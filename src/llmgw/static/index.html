선택한 계정 아래의 팀·사용자·키를 만들고 수정·삭제한다. 삭제는 하위 리소스가 없어야 하고, 키 재발급 시 옛 키는 즉시 무효가 된다.

비용은 게이트웨이가 토큰 수와 자체 단가 표로 계산한 추정치다. AWS 청구서와 다를 수 있다. 지연 백분위와 서비스 전체 메트릭은 CloudWatch LLMGateway 네임스페이스에서 확인한다.
